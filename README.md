My research connects **AI, computer vision, optimization, data mining, and databases**. Recent publications include:

- **[Structure-Aware RGB Channel Reconstruction for YOLOv8-Based Oyster Mushroom Detection](https://www.mdpi.com/2077-0472/16/18/1985)**  
  *Agriculture*, 2026 · Computer vision and agricultural detection.
- **[Directional Alignment Penalty: A Lightweight Localization Loss for Improved Bounding Box Regression in YOLOv8](https://doi.org/10.3390/app16168286)**  
  *Applied Sciences*, 2026 · Object detection and bounding-box localization.
- **[Implementation of Modified Effective Butterfly Optimizer in Solving Multi-Objective Pareto Optimal Power Flow Problem with Renewable Uncertainties](https://doi.org/10.3390/biomimetics11060418)**  
  *Biomimetics*, 2026 · Multi-objective optimization and renewable-energy systems.
- **[Letter and Person Recognition in Freeform Air-Writing Using Machine Learning Algorithms](https://doi.org/10.1109/ACCESS.2025.3536609)**  
  *IEEE Access*, 2025 · Machine learning and air-writing recognition.

### Technical interests

- **Generative AI:** image, video and audio workflows; vision-language models; LoRA and fine-tuning; captioning and dataset preparation.

- **Research:** computer vision, NLP, optimization, record linkage, e-commerce data systems, sentiment analysis, and digital forensics.
